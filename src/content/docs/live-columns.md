---
title: Live columns
description: Turn a category into a static list, an RSS or Atom feed, or a GitHub issues, pull requests, and releases feed.
---

Each category column has a source type, set in the category dialog:

- **Static bookmarks**, a list you edit yourself
- **RSS / Atom feed**, from a feed URL
- **GitHub repository**, as `owner/repo`, or `@me` through the `gh` CLI

A GitHub column can show issues and pull requests, only issues, only pull requests, or releases.

Megamenu ships a **Live Pulse** space as a showcase: Hacker News, Omarchy GitHub activity, and tech news. Use it as a pattern, or replace the feeds.

## Keep an entry

A live row is not a bookmark until you pin it. The pin control on a live entry saves that entry as a permanent bookmark in the space. Refresh the column when you want a newer fetch.
