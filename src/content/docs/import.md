---
title: Import bookmarks
description: Pull bookmark folders from installed browsers or an HTML export into the active space.
---

**Import** in the top bar reads bookmark profiles that are already on this computer:

- Chromium-based browsers: Brave, Chromium, Chrome, Vivaldi, Edge
- Firefox, Zen, and LibreWolf (`places.sqlite`)
- An HTML export at `~/Downloads/bookmarks.html`

Each folder you select becomes a color-coded category in the **active** space. Favicons are cached under `~/.local/share/omarchy-megamenu/favicons/` the next time Megamenu opens.

If the scan finds nothing, export `bookmarks.html` into `~/Downloads` and open Import again.
