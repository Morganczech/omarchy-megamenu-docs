---
title: Živé sloupce
description: Kategorie může být statický seznam, RSS nebo Atom feed, nebo GitHub feed issues, pull requestů a vydání.
---

Každý sloupec kategorie má typ zdroje. Nastavuje se v dialogu kategorie:

- **Statické záložky**, seznam, který upravuješ sám
- **RSS / Atom feed** z URL feedu
- **GitHub repozitář** ve tvaru `owner/repo`, nebo `@me` přes CLI `gh`

GitHub sloupec umí issues i pull requesty, jen issues, jen pull requesty, nebo vydání.

Součástí Megamenu je ukázkový prostor **Live Pulse**: Hacker News, aktivita na GitHubu Omarchy a technické zprávy. Můžeš ho nechat jako vzor, nebo feedy vyměnit.

## Nechat si položku

Živý řádek není záložka, dokud ho nepřipneš. Připnutí u živé položky ji uloží jako trvalou záložku v prostoru. Sloupec obnov, když chceš novější stažení.
