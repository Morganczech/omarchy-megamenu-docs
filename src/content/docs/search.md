---
title: Search
description: Filter every space as you type, and open Omarchy actions, apps, and saved commands with >.
---

Type anywhere in the menu. Megamenu filters bookmarks and commands across **all spaces**. Matches from another space show up in their own column, next to Omarchy system actions and installed `.desktop` applications.

The same query also matches [notes](/notes/) by title, file name, or badge. Choosing a match opens that note. The file body is not searched.

Actions use the names you already see in Omarchy, such as `Style › Theme`, `Style › Background`, `System › Lock`, `Trigger › Capture › Screenshot`, and `Setup › Monitors`.

## The `>` view

Start the query with `>` to open a full-width list of Omarchy actions, applications, and saved commands:

```text
> theme
> ghostty
> restic
```

From that list, launch with `Enter`, or pin an action or app into a Megamenu category.

## Frequent

Open Megamenu with an empty search field and a **Frequent** strip lists the bookmarks, apps, and commands you launch most often, ranked by launch count. Slots `1`–`6` still launch the orbit while that field is empty.
